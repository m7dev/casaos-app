# CasaOS Android — full-screen WebView

Особливості:
- CasaOS відкривається на весь екран без адресного рядка.
- IP/порт зберігається в застосунку.
- Налаштування доступні через системне меню Android / клавішу MENU.
- JavaScript, localStorage, cookies і авторизація WebView підтримуються.
- Back повертає по історії CasaOS.
- Оновлення сторінки доступне з меню.
- Підтримуються `192.168.1.100`, `192.168.1.100:80`, `192.168.1.100:8080`, http/https.

## Як зібрати APK з телефону (через GitHub Actions)

1. Встанови додаток **GitHub** на телефон (або відкрий github.com у браузері) і залогінься / зареєструйся.
2. Створи новий **приватний або публічний репозиторій**, наприклад `casaos-android`.
3. Заливи туди весь вміст цього проєкту (усі файли й папки з цього архіву, зберігаючи структуру: `app/`, `.github/`, `build.gradle` тощо). Найпростіше — через веб-інтерфейс GitHub: "Add file" → "Upload files", перетягнути весь вміст архіву.
4. Після заливки перейди у вкладку **Actions** репозиторію — збірка запуститься автоматично (workflow `Build APK`).
5. Зачекай 3-7 хвилин, поки збірка завершиться (зелена галочка).
6. Відкрий останній запуск workflow, прокрути вниз до розділу **Artifacts** — там буде файл `CasaOS-debug-apk`. Завантаж його (це `.zip`, всередині — `app-debug.apk`).
7. Розпакуй та встанови `app-debug.apk` на телефоні (дозволь встановлення з невідомих джерел, якщо попросить).

Це debug-збірка — вона не підписана для Google Play, але встановлюється і працює нормально на будь-якому Android-пристрої.
