# ShelterX Android — full-screen Home Server WebView

Особливості:
- Відкривається на весь екран без адресного рядка.
- IP/порт зберігається в застосунку.
- Налаштування доступні через системне меню Android / клавішу MENU.
- JavaScript, localStorage, cookies і авторизація WebView підтримуються.
- Логін і пароль (необов'язково) зберігаються зашифровано та автоматично підставляються у форму входу на сторінці.
- Back повертає по історії.
- Оновлення сторінки доступне з меню.
- Підтримуються http/https.

Це debug-збірка — вона не підписана для Google Play, але встановлюється і працює нормально на будь-якому Android-пристрої.
